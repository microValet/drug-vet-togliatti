# Друг — сайт ветеринарной клиники в Тольятти

Подарочная концепция сайта с прямыми переходами в сообщество ВКонтакте, телефон и Яндекс Карты. Без форм, базы данных, аналитических трекеров и сторонних JavaScript-библиотек.

Сайт: https://microvalet.github.io/drug-vet-togliatti/

## Публикация

GitHub Pages: ветка `main`, каталог `/docs`. Обновления публикуются после push в `main`.

## Локальный просмотр

`python -m http.server 8765 --directory docs`

Откройте http://localhost:8765/.

## Контент

Контакты: +7 (8482) 37-02-36, Тольятти, Дзержинского, 78А. Ссылку сообщества предоставил заказчик; соответствие клинике дополнительно подтверждено ссылкой из карточки https://vetpapa.ru/tolyatti/clinic/drug__tolyatti/.

График из открытых справочников помещён в FAQ с просьбой уточнить его перед поездкой. Точные услуги, цены и состав врачей не заявляются без подтверждения клиники. MAX не подключён: подтверждённого адреса нет. Автоматической записи нет; время подтверждается сотрудником клиники. Концепция подписана в подвале, не выдаёт себя за согласованный официальный сайт.

Фото собаки — иллюстративное, не фото пациента клиники: https://images.unsplash.com/photo-1552053831-71594a27632d. Источник Unsplash; не использовать как свидетельство оказанного лечения. Шрифт Manrope — SIL Open Font License, лицензия в `docs/assets/OFL.txt`.

Контакты, график и дальнейшее использование дизайна стоит актуализировать с командой клиники.

## Фирменный стиль

Использованы настоящие обложка и аватар публичного сообщества https://vk.ru/vetklinikatlt, полученные 20 ноября 2026: `vk-cover.jpg` и `vk-logo.jpg`. Основной цвет обложки — #3b2997 (RGB 59, 41, 151). Заголовки Oswald повторяют узкий шрифт с заглавными буквами; это подобранный аналог. Шрифт Oswald лицензирован по SIL OFL, лицензия: `docs/assets/Oswald-OFL.txt`.
